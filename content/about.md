## 🎯 关于 TokenFree

**TokenFree** 是一个专注于整理和分享全球免费/低成本 AI API Token 渠道的信息平台。

我们的使命是：**让每位开发者都能平等、自由地使用 AI 能力**。

无论你是个人开发者、学生、初创团队，还是大型企业，都能在这里找到适合你的 AI 接口资源。

## 🛠️ 技术架构

- **静态生成**: [Hugo](https://gohugo.io/) + PaperMod 主题
- **自动部署**: GitHub Actions → VPS (rsync + Docker)
- **Web 服务器**: Caddy (自动 HTTPS)
- **托管**: 腾讯云 VPS
